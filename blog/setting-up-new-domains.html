Setting Up New Domains: A Complete Guide

18 min read 156 views

Setting up a complete infrastructure around a new domain name involves multiple moving parts. After going through this process with several projects, I've developed a systematic approach that ensures security, performance, and maintainability from day one.

Domain Registration

The foundation of your online presence starts with choosing the right domain registrar and securing your domain properly.

Choosing a Registrar

For most cases, I prefer Namecheap as my go-to domain registrar. They offer:

  • Competitive pricing across a wide range of TLDs
  • Solid customer support and user-friendly interface
  • Free WHOIS privacy protection
  • Reliable service with good uptime

Other reputable options include Google Domains (now part of Squarespace), Cloudflare Registrar, and Gandi. The key factors to consider are pricing, security features, and ease of management.

Security First

Before anything else, enable Two-Factor Authentication (2FA) on your registrar account. Your domain registrar has complete control over your domain, making account security paramount. I also recommend:

  • Using a unique, strong password for your registrar account
  • Enabling domain lock/transfer protection
  • Setting up account notifications for any changes

Initial Configuration

Once registered, immediately change the nameservers from the registrar's default to a proper DNS service. Don't worry about configuring DNS records yet—we'll handle that in the next section.

DNS Management

Proper DNS setup is crucial for performance, security, and flexibility. I strongly recommend separating DNS management from domain registration.

Why Cloudflare?

Cloudflare is my preferred DNS provider for several reasons:

  • Performance: World-class infrastructure with extremely fast propagation times
  • Cost: Free plan covers most needs perfectly
  • Features: Advanced features like proxy services, DDoS protection, and analytics
  • API Access: Robust API for automation and dynamic DNS scenarios

Essential DNS Records

Here are the fundamental DNS records you'll need for most projects:

A and AAAA Records

example.com        A     192.0.2.1
www.example.com    A     192.0.2.1
example.com        AAAA  2001:db8::1

CNAME for Subdomains

blog.example.com   CNAME example.com
api.example.com    CNAME example.com

Root Domain CNAME Flattening

One of Cloudflare's standout features is CNAME flattening. This allows you to point your root domain to services like Netlify or Vercel using a CNAME record, which is normally not allowed. This is incredibly useful for modern static site hosting.

DNSSEC

Enable DNSSEC for additional security. Cloudflare makes this easy with one-click activation. While not every service requires it, having DNSSEC enabled protects against DNS spoofing attacks.

Dynamic DNS

For homelab or development scenarios, Cloudflare's API integrates seamlessly with dynamic DNS solutions. Many routers, including OpenWRT, have built-in support for Cloudflare dynamic DNS updates.

Static Web Hosting

For most modern web applications, static hosting with a JAMstack approach offers unbeatable performance and simplicity.

Netlify: The Modern Choice

Netlify has become my preferred platform for static site hosting:

Setup Process

  1. Create your website (HTML, React, Vue, etc.)
  2. Push your code to GitHub/GitLab
  3. Connect Netlify to your repository
  4. Configure build settings (if needed)
  5. Set up custom domain with automatic HTTPS

Advanced Features

  • Continuous Deployment: Automatic builds on every push
  • Branch Previews: Test changes before merging
  • Edge Functions: Serverless functions at the edge
  • Form Handling: Built-in form processing
  • Analytics: Privacy-focused web analytics

Domain Configuration

Setting up your custom domain on Netlify is straightforward:

  1. In Netlify, go to Domain Management
  2. Add your custom domain
  3. Point your DNS records to Netlify's servers
  4. Enable automatic HTTPS (Let's Encrypt)

Alternative Platforms

While Netlify is excellent, other platforms worth considering include:

  • Vercel: Great for Next.js applications
  • GitHub Pages: Simple and free for open source projects
  • Cloudflare Pages: Integrated with Cloudflare's ecosystem

Email Configuration

Professional email on your custom domain is essential for business credibility and communication.

Fastmail: Professional Email Done Right

While Google Workspace is popular, I prefer Fastmail for custom domain email:

Why Fastmail?

  • Privacy-focused: Not an advertising company
  • Performance: Fast, reliable service
  • Features: Advanced filtering, custom domains, aliases
  • Standards-compliant: Works with any email client
  • Reasonable pricing: $5/month for individuals

DNS Configuration for Email

Setting up email requires several DNS records:

MX Records

example.com    MX    10    in1-smtp.messagingengine.com
example.com    MX    20    in2-smtp.messagingengine.com

SPF Record

example.com    TXT   "v=spf1 include:spf.messagingengine.com ?all"

DKIM Records

Fastmail provides specific DKIM records to add to your DNS for email authentication.

DMARC Policy

_dmarc.example.com    TXT    "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"

Email Aliases and Forwarding

One of Fastmail's great features is wildcard aliases. You can set up *@example.com to route to your main inbox, or create specific aliases for different purposes:

  • hello@example.com - General inquiries
  • support@example.com - Customer support
  • noreply@example.com - System emails

SSL/TLS and Security

Security should be built in from the ground up, not added as an afterthought.

Automatic HTTPS

Most modern hosting platforms provide automatic HTTPS via Let's Encrypt:

  • Netlify: Automatic with custom domains
  • Vercel: Built-in for all deployments
  • Cloudflare Pages: Automatic with Cloudflare certificates

Security Headers

Implement proper security headers through your hosting platform or Cloudflare:

Strict-Transport-Security: max-age=31536000; includeSubDomains
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin

Content Security Policy

Start with a basic CSP and gradually make it more restrictive:

Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'

Monitoring and Maintenance

Set up monitoring to ensure your infrastructure remains healthy and secure.

Uptime Monitoring

Use services like UptimeRobot or Pingdom to monitor your website availability and receive alerts if issues arise.

SSL Certificate Monitoring

While modern platforms handle certificate renewal automatically, it's wise to monitor certificate expiration dates as a backup.

Domain Renewal Reminders

Set up calendar reminders well in advance of domain renewal dates. Consider enabling auto-renewal where available.

Backup and Recovery

Even with reliable services, having a backup plan is essential.

DNS Backup

Export your DNS configuration regularly. Most providers offer export functionality for easy migration if needed.

Website Backup

For static sites, your Git repository serves as your backup. For dynamic sites, implement regular automated backups of both code and data.

Cost Optimization

Modern infrastructure can be very cost-effective if set up properly.

Typical Costs

  • Domain: $10-15/year
  • DNS: Free (Cloudflare)
  • Hosting: Free (Netlify/Vercel starter plans)
  • Email: $60/year (Fastmail)
  • Monitoring: Free tier often sufficient

Total annual cost: Around $70-80 for a professional setup

Automation and Infrastructure as Code

As your projects grow, consider automating common tasks.

DNS Automation

Use Terraform or similar tools to manage DNS records as code:

resource "cloudflare_record" "www" {
  zone_id = var.cloudflare_zone_id
  name    = "www"
  value   = "example.com"
  type    = "CNAME"
  proxied = true
}

CI/CD Integration

Integrate domain setup into your CI/CD pipelines for consistent deployments across environments.

Conclusion

Setting up modern domain infrastructure doesn't have to be complicated or expensive. By choosing the right tools and following security best practices from the start, you can create a robust foundation for your online projects.

The key takeaways:

  • Security first: Enable 2FA and use strong, unique passwords
  • Separate concerns: Use specialized services for DNS, hosting, and email
  • Automate where possible: Modern platforms handle most routine tasks automatically
  • Monitor everything: Set up alerts for critical services
  • Plan for growth: Choose services that can scale with your needs

The modern web infrastructure landscape offers incredible capabilities at accessible prices. Take advantage of these tools to build something amazing.
